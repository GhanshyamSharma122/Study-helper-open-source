# Security policy

## Reporting a vulnerability

Do not report a security vulnerability in a public issue.

Contact the project maintainer through the private contact method listed on the GitHub profile. Include the affected file, the steps that reproduce the issue, and the possible effect.

## Secret handling

Keep API keys in environment variables. Never commit `.env` files or secret values. Revoke a key immediately when it appears in a commit, log, issue, or public post.
