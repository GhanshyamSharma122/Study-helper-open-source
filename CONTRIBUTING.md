# Contributing

Thank you for your interest in Study Helper.

## Before you create a change

1. Read the README.
2. Open an issue for a large change.
3. Create a branch from `main`.
4. Keep each pull request focused on one change.

## Before you create a pull request

1. Run `npm test`.
2. Remove local files, database files, and secrets.
3. Update the README when the change affects setup or behavior.
4. Describe the change and the test result in the pull request.

Do not commit API keys, personal data, `.env` files, or generated backup files.
